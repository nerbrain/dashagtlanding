Every app comes as a kit.

This is everything inside the leave request app above. Each part is a dashAGT building block you configure, not code you write.

A1  FormLeave request form
A2  TableAll requests, for HR
A3  Approval chainSupervisor, then HR
A4  DocumentApproval letter, as a PDF
A5  NotificationSMS when it’s decided
A6  ButtonSubmit request

Assembly

  1. 1Snap A1 onto a page and point it at your leave table, or import the spreadsheet you use today.
  2. 2Add A2 on a second page so HR can see every request and filter by branch.
  3. 3Clip A3 to A6, so pressing Submit starts the approval chain.
  4. 4Attach A4 and A5 to the approval, then publish.
